# Lily58 configuration

ZMK config for a Lily58 with nice!nano v2 controllers and nice!oled displays
(via [zmk-nice-oled](https://github.com/mctechnology17/zmk-nice-oled)).
ZMK is pinned to the `v0.3-branch` in `config/west.yml` and `.github/workflows/build.yml`.

The `main` layer follows the Colemak-DHm.

## Building

Firmware is built by GitHub Actions on every push (see `build.yaml`), or locally with Nix:

```sh
nix build            # result/zmk_left.uf2, result/zmk_right.uf2
nix run .#flash      # copy the firmware to a half in bootloader mode
nix run .#update     # update flake.lock and the west deps hash (zephyrDepsHash)
nix develop          # shell with west and the Zephyr toolchain
```

After changing `config/west.yml` (e.g. bumping ZMK), run `nix run .#update`
or set `zephyrDepsHash` in `flake.nix` to the hash `nix build` reports.

## Layers

Encoders: left = volume, right = page up/down (on every layer).
Holding `SYM` and `NUM` together activates `SYS` (tri-layer).

### Layer: system (SYM + NUM)

Same as navigation, plus Bluetooth and firmware controls. `Boot`/`Reset` act on
the half they are pressed on, so each half has its own pair.

```plain
.-----------------------------------------.                    .-----------------------------------------.
|BT CLR| BT 0 | BT 1 | BT 2 | BT 3 | BT 4 |                    |  F7  |  F8  |  F9  | F10  | F11  | F12  |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|BT PRV|BT NXT| Tab  | PgDn | PgUp |      |                    |  F1  |  F2  |  F3  |  F4  |  F5  | F6   |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|      |      |  <-  |   v  |   ^  |  ->  |-------.    .-------| SkGui| SkAlt|SkCtrl|SkShft|      |      |
|------+------+------+------+------+------|       |    |       |------+------+------+------+------+------|
| Boot | Reset|      |      |      |      |-------|    |-------|      |      |      |      | Reset| Boot |
`-----------------------------------------/       /     \      \-----------------------------------------'
                  |       |      |     | /       /       \      \  |       |      |      |
                  `--------------------' '------'         '------' '---------------------'
```
